A language pack that adds Japanese UI support to Aquafox, the PowerPC Mac browser derived from TenFourFox. This pack is based on Firefox 45.9.0esr's official Japanese language pack and includes roughly 80 additional Aquafox-specific translations.

Don't have Aquafox itself yet? Get it from the official Aquafox download page first, then come back here for the Japanese pack.

Installation Steps

  1. Download aquafox-ja.dmg from the button above and double-click it to mount.
  2. Quit Aquafox completely (Aquafox menu → Quit Aquafox).
  3. Double-click Install.command in the mounted disk. Terminal opens and puts the language pack in place and sets the UI language for you.
  4. When it says “Done”, close the Terminal window and launch Aquafox. The interface will appear in Japanese.

Note: if Aquafox is still running, the installer stops without changing anything. Quit Aquafox and run it again. For manual installation, see README.rtf in the dmg (it opens in Tiger's TextEdit).

インストール手順

  1. 上のボタンから aquafox-ja.dmg をダウンロードし、ダブルクリックしてマウントします。
  2. Aquafox を完全に終了します（メニューの「Aquafox」→「Quit Aquafox」）。
  3. マウントされたディスクの中の Install.command をダブルクリックします。 ターミナルが開き、言語パックの配置と日本語表示の設定を自動で行います。
  4. 「完了しました」と表示されたらターミナルのウインドウを閉じ、Aquafox を起動すると日本語表示になります。

※ Aquafox が起動したままだと、インストーラは何も変更せずに中止します。Aquafox を終了してからもう一度実行してください。 手動でインストールしたい場合は、dmg 内の README.rtf（Tiger のテキストエディットで読めます）に手順があります。
