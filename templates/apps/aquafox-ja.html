A language pack that adds Japanese UI support to Aquafox, the PowerPC Mac browser derived from TenFourFox. This pack is based on Firefox 45.9.0esr's official Japanese language pack and includes roughly 80 additional Aquafox-specific translations.

Don't have Aquafox itself yet? Get it from the official Aquafox download page first, then come back here for the Japanese pack.

Installation Steps

  1. Download ja-aquafox.xpi from the button above.
  2. Open the following folder in Finder (from the menu: Go → Go to Folder..., then paste the path below):
    ~/Library/Application Support/Aquafox/Profiles/
  3. Open the profile folder inside (named something like xxxxxxxx.default) and then open the extensions folder. Create it if it does not exist.
  4. Rename the downloaded ja-aquafox.xpi to langpack-ja@firefox.mozilla.org.xpi and place it in that extensions folder.
  5. Launch Aquafox, open about:config via the menu: Aquafox → Preferences → Advanced → General, then set general.useragent.locale to ja. Create it if it is missing.
  6. Restart Aquafox and the interface will appear in Japanese.

Note: place and rename the file with Aquafox completely quit. If you drop it into the extensions folder and rename it while Aquafox is running, it will not be picked up and the UI stays in English. If that happens, download ja-aquafox.xpi again, quit Aquafox, put it back in the same folder with the correct name (overwriting the old one), then launch.

インストール手順

  1. 上のボタンから ja-aquafox.xpi をダウンロードします。
  2. Finder で以下のフォルダを開きます（「移動」メニュー →「フォルダへ移動...」で下記パスを貼り付けると早いです）。
    ~/Library/Application Support/Aquafox/Profiles/
  3. 中にあるフォルダ（xxxxxxxx.default のような名前）を開き、extensions フォルダを開きます（無ければ新規作成してください）。
  4. ダウンロードした ja-aquafox.xpi を、 langpack-ja@firefox.mozilla.org.xpi という名前に変更してから、 その extensions フォルダに入れます。
  5. Aquafox を起動し、メニューバーの「Aquafox」→「Preferences」→「詳細」→「全般」から about:config を開き、general.useragent.locale を ja に設定します（無ければ新規作成してください）。
  6. Aquafox を再起動すると日本語表示になります。

※ ファイルの配置とリネームは、Aquafox を完全に終了した状態で行ってください。起動したまま extensions フォルダにファイルを入れて名前を変えても読み込まれず、日本語になりません。 うまくいかなかった場合は、ja-aquafox.xpi をダウンロードし直し、Aquafox を終了してから、 同じフォルダに正しい名前で置き直して（上書き）起動してください。
